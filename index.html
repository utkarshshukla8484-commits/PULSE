    Project Architecture & Technical Highlights

    PULSE System Overview

    1. Zero-Backend Architecture

    100% of data structures, timers, and state machine models run in browser memory without relying on cloud APIs, databases, or third-party web trackers. Completely private and works offline.

    2. Web Storage API (`localStorage`)

    Session performance metrics (reps, sets, elapsed seconds, estimated kcal, timestamps) are serialized into JSON and stored persistently across page reloads via the browser's native key-value engine.

    3. Web Audio API Sound Synthesizer

    Countdown beeps, button tick frequencies, and victory chimes are synthesized directly in real time using AudioContext oscillators (sine/square waveforms), eliminating the need for external MP3 assets.

    4. Web Speech API Voice Coach

    Native browser window.speechSynthesis acts as a hands-free virtual trainer, providing auditory cues ("Starting Push-ups", "Halfway there", "Rest now") during demanding sets.

    5. Vector SVG Rigging & CSS Keyframes

    Every exercise avatar is constructed with clean SVG vector geometry. Movement is coordinated via hardware-accelerated CSS keyframe matrices (rotations, joint pivots, and isometric breathing animations).

    6. Physiological MET Calorie Model

    Energy expenditure is computed dynamically using clinical Metabolic Equivalent of Task (MET) ratings mapped to each exercise's real-time duration and set volume.
